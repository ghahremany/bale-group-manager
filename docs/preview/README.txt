این فایل‌ها فقط «پیش‌نمایش استاتیک» رابط کاربری هستند (HTML + CSS درون‌خطی)
و بخشی از برنامه نیستند؛ برای دیدن ظاهر پنل و نصب‌کننده بدون اجرای PHP.

- panel-dashboard.html : داشبورد پنل با داده‌های نمونه + اسپارک‌لاین‌های ۱۴ روزه
- panel-analytics.html : گزارش نموداری (میله‌ای، خطی، دونات، میله‌ای افقی، ساعتی، دعوت)
- panel-backup.html    : بکاپ و گزارش خودکار (ساخت/دانلود/بازیابی + تنظیمات)
- panel-referrals.html : زیرمجموعه‌گیری (آمار، نمودار، تاپ معرف‌ها، لیست دعوت‌ها)
- panel-broadcast.html : صف ارسال همگانی (ارسال، زمان‌بندی، نرخ، پیشرفت دسته‌ها)
- panel-recovery.html  : کدهای بازیابی + لاگ امنیت OTP
- panel-recover.html   : صفحه ورود با کد بازیابی (فراموشی رمز / نبود دسترسی به بله)
- panel-store.html     : انبار و کالاها (تایید کالا، موجودی، کمپین تبلیغ)
- panel-store-coupons.html : تب کد تخفیف (درصدی/ثابت، سقف استفاده، محدوده کالا/فروشنده)
- panel-modules.html   : صفحه ماژول‌ها (روشن/خاموش کردن کانال، اخبار، دعوت، اجبار عضویت، نظرسنجی، قرعه‌کشی، کانال خبر، مدیریت با ربات)
- panel-module-channels.html  : ماژول مدیریت کانال (ثبت کانال + ارسال پست)
- panel-module-news.html      : ماژول اخبار کانال (نوشتن، زمان‌بندی، ارسال)
- panel-module-referrals.html : ماژول زیرمجموعه‌گیری (تایید/رد دعوت، تاپ معرف‌ها)
- panel-module-forcejoin.html : ماژول اجبار عضویت و بازی (گیت عضویت + سؤال ضد ربات)
- panel-module-poll.html      : ماژول نظرسنجی (ساخت، انتشار، نوار نتیجه، بستن/انقضا) — ۱.۵
- panel-module-raffle.html    : ماژول قرعه‌کشی (جایزه، مهلت، شرط عضویت، انتخاب برنده) — ۱.۵
- panel-module-newschannel.html : ماژول کانال خبر (منابع، کلیدواژه و دسته‌بندی، کانال مقصد، صندوق ورودی) — ۱.۵
- panel-module-adminbot.html   : ماژول مدیریت با ربات (اتصال چت، کد یک‌بارمصرف، هشدار امنیتی، انبار و کالاهای کم‌موجود) — ۱.۶
- panel-orders.html    : سفارش‌ها، تایید رسید پرداخت، تغییر وضعیت
- panel-wallets.html   : کیف پول، برداشت‌ها و تنظیمات فروشگاه
- shop-dashboard.html  : داشبورد پنل فروشگاه کاربران (۱.۳)
- shop-orders.html     : سفارش‌های من در پنل کاربران
- shop-wallet.html     : کیف پول و کمیسیون کاربر
- shop-login.html      : ورود کاربران با لینک یک‌بارمصرف بله
- panel-group.html     : صفحه مدیریت یک گروه
- panel-system.html    : صفحه سیستم و وب‌هوک
- installer-step1.html : مرحله ۱ نصب‌کننده

نکته‌های فنی:
- تمام CSS درون خود فایل است؛ هیچ فایل، فونت، اسکریپت یا CDN خارجی بارگذاری نمی‌شود،
  بنابراین در محیط‌های سندباکس/آفلاین هم دقیقاً مثل پنل واقعی دیده می‌شود.
- نمودارها SVG تولیدشده در سمت سرور هستند (بدون Chart.js) و همین‌طور در این فایل‌ها کار می‌کنند.
- در پیش‌نمایش استاتیک، دکمه‌ها و فرم‌ها غیرفعال‌اند (onsubmit=false) و لینک‌ها به صفحه واقعی نمی‌روند.

برای دیدن نسخه واقعی: نصب‌کننده را اجرا کنید و به `/panel/` بروید.
